Open-source · SDK · IA

GSEP™ Core

Librería open-source que convierte cualquier agente de IA existente en un agente auto-evolutivo en 3 líneas de código. Los prompts dejan de ser texto estático y se convierten en organismos vivos que mutan, se adaptan y mejoran con cada interacción. 1,931 tests pasados. Arquitectura de cromosomas de 5 capas con seguridad integrada: firewall C3 (53 patrones de detección de prompt injection), sistema inmune C4 (6 checks de output), 22 módulos de seguridad enterprise y cero dependencias npm externas.
